Tony, the Empathic A.I.

Problem

Many artificial intelligence systems these days lean heavily towards the data-driven approach.

But this is far from reliable.

Say if the data sets with which they are trained are not broad enough, the end results can wreak havoc without users (or even the developers themselves) knowing.

Buildiful Solution

As an attempt to cover more bases, Tony the empathic A.I. comprises two core parts:

  1. A system that mimics the neuroscience behind empathy -- or, in other words, how empathy works in our brain.

  2. A machine learning system trained by real-life data from all cultural backgrounds.
